# 🗺️ The Lost Treasure - Python Game

## 🎮 About the Game

**The Lost Treasure** is a simple console-based adventure game built with Python as part of the **Data Science Track – One-Day Python Challenge**.

In this game, the player becomes an explorer searching for a legendary treasure inside a mysterious cave. The player's decisions affect the story and the final score.

The goal is to make the right choices, collect points, find the treasure, and escape safely! 💎

---

## 🎯 Challenge Requirements

This project was designed to practice the fundamental concepts of Python programming:

- User interaction using `input()`
- Decision-making using `if`, `elif`, and `else`
- Variables and score tracking
- Conditional logic
- Clear game outcomes
- Simple and organized Python code

---

## 🕹️ How the Game Works

The player goes through several decisions during the adventure.

### 1. Choose a Path 🛤️

The player chooses between three different paths:

- Dark tunnel
- Tunnel with a light
- Narrow tunnel with strange sounds

Each choice gives the player a different score and result.

### 2. Open the Wooden Door 🚪

The player must decide whether to:

- Break the door
- Search for a key

The result depends on the player's previous score.

### 3. Find the Treasure Chest 💎

At the end, the player chooses between three symbols:

- Moon
- Sun
- Star

The correct choice gives the player additional points.

### 4. Final Result 🏆

The final score determines the outcome of the game:

- 🏆 High score → Legendary treasure found
- 🥇 Medium score → Valuable treasure found
- 🙂 Low score → Survived but missed the legendary treasure
- 💀 Negative score → Game Over
